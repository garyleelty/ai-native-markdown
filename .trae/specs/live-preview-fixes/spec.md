# 实时预览功能修复 Spec

## Why

当前实时预览（Live Preview）模式存在多个功能缺陷和用户体验问题，导致该模式在实际使用中不可用：
1. 工具栏格式化按钮在实时预览模式下不生效
2. 键盘快捷键（Ctrl+B, Ctrl+I 等）在实时预览模式下不工作
3. 从源码模式切换到实时预览时，光标位置没有正确同步
4. 撤销/重做功能在实时预览模式下不可用
5. 搜索替换功能在实时预览模式下不可用
6. 滚动位置在模式切换时丢失

这些问题导致实时预览模式成为一个"半成品"功能，用户无法在该模式下进行有效的编辑工作。

## What Changes

### 1. 快捷键支持
- 在 `LiveMarkdownEditor` 中添加完整的格式化快捷键支持
- 支持的快捷键：粗体(Ctrl+B)、斜体(Ctrl+I)、链接(Ctrl+K)、撤销(Ctrl+Z)、重做(Ctrl+Y)、搜索(Ctrl+F)

### 2. 光标位置同步
- 从源码模式切换到实时预览时，根据当前光标位置计算所在行
- 实时预览模式下的光标行号与源码模式保持同步

### 3. 滚动位置同步
- 模式切换时保持滚动位置一致
- 使用 `_scrollController` 在两种模式间共享滚动状态

### 4. 工具栏按钮联动
- 确保工具栏的格式化按钮在实时预览模式下也能正常工作
- 在 `NotePanel` 中统一处理格式化操作，不依赖具体的编辑模式

### 5. 撤销/重做支持
- 在实时预览模式下支持撤销/重做
- 与源码模式共享撤销/重做历史

### 6. 搜索替换支持
- 在实时预览模式下支持搜索和替换功能

## Impact

- **修改文件**:
  - `lib/features/editor/widgets/live_markdown_editor.dart` - 添加快捷键和格式化支持
  - `lib/features/editor/widgets/note_panel.dart` - 模式切换时的光标/滚动同步

- **影响范围**: 编辑器模块，不影响其他功能模块
- **向后兼容**: 完全兼容，仅修复问题不改变现有 API

## ADDED/MODIFIED Requirements

### 可验证的需求

1. **[ ] 实时预览模式下 Ctrl+B 可以切换选中文本的粗体格式**
2. **[ ] 实时预览模式下 Ctrl+I 可以切换选中文本的斜体格式**
3. **[ ] 实时预览模式下工具栏格式化按钮正常工作**
4. **[ ] 从源码模式切换到实时预览时，光标保持在同一行**
5. **[ ] 模式切换时滚动位置基本保持一致**
6. **[ ] 实时预览模式下 Ctrl+Z 可以撤销操作**
7. **[ ] 实时预览模式下 Ctrl+Y 可以重做操作**
8. **[ ] 实时预览模式下 Enter 键正确换行并延续列表/引用格式**
9. **[ ] 实时预览模式下 Backspace 在行首可以合并到上一行**

## 设计决策

### 决策1：统一通过 _textController 处理格式化操作
- **问题**：格式化操作当前直接操作 `_textController`，但实时预览模式下的 `_lineControllers` 是独立的
- **方案**：所有格式化操作统一通过 `_textController` 进行，然后通过 `_onControllerChanged` 同步到 `_lineControllers`
- **理由**：这样可以确保两种模式下的格式化行为一致，且共享撤销/重做历史

### 决策2：实时预览模式的光标位置通过 _textController.selection 计算
- **问题**：实时预览模式使用 `_cursorLine` 跟踪当前编辑行，但与 `_textController` 的光标位置不同步
- **方案**：从源码模式切换到实时预览时，根据 `_textController.selection.baseOffset` 计算所在行号
- **理由**：确保模式切换时光标位置的连续性

### 决策3：不支持实时预览模式下的搜索高亮
- **问题**：搜索替换功能需要在文本中高亮匹配项，实时预览模式的渲染方式较复杂
- **方案**：实时预览模式下支持搜索替换功能，但搜索高亮暂时只在源码模式下显示
- **理由**：搜索功能的核心是定位和替换，高亮是增强功能，后续可以优化
