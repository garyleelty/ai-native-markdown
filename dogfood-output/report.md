## 🔴 ISSUE-001: 属性面板功能完全缺失

**严重程度：** 高

**问题描述：**
当前应用完全缺少属性面板（Properties Panel）功能。用户无法通过可视化界面编辑 YAML frontmatter。

**当前状态：**
- 应用支持基础的 frontmatter 解析（`src/utils/metadata.ts`）
- 知识索引可以存储 frontmatter 数据
- 但没有 UI 组件让用户编辑这些属性

**期望行为：**
参考 Obsidian，用户应该在侧边栏看到一个"属性"标签页，可以：
- 查看当前笔记的所有 frontmatter 属性
- 添加/编辑/删除属性
- 选择属性类型（文本、日期、标签等）

**影响：**
- 用户无法方便地管理笔记元数据
- 需要手动编辑 YAML，门槛较高
- 与 Obsidian 功能差距明显

**相关文件：**
- `src/utils/metadata.ts` - 已有解析逻辑
- `src/services/knowledgeIndex.ts` - 已有索引逻辑

**下一步：**
按照 `docs/superpowers/specs/2026-06-08-properties-panel-design.md` 设计文档实现属性面板

## 🟡 ISSUE-003: 全局正则搜索功能不稳定

**严重程度：** 中

**问题描述：**
正则搜索功能之前（ISSUE-004）发现 lastIndex 问题，虽然已修复，但仍有改进空间。

**当前实现（`src/composables/useGlobalSearch.ts`）：**
```typescript
// 每次都创建新的正则实例
const lineRegex = new RegExp(pattern, 'gi')
if (lineRegex.test(lines[i])) {
  matches.push({ lineNumber: i + 1, lineContent: lines[i].trim().slice(0, 200) })
}
```

**潜在问题：**
1. 正则表达式无效时没有错误处理
2. 对于大文件性能可能不佳
3. 没有取消按钮，用户无法中断长时间搜索

**建议改进：**
- 添加正则表达式语法验证
- 实现 Web Worker 进行后台搜索
- 添加取消机制
